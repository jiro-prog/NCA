## 3. どの仕組みで戻りが速くなるのか（候補。まだ決めない）

設計書に1文で書くべきもの。§7 の模擬の結果を見てから、そうと決める。

  硬さ（書き換えにくくする）は、切り替えのたびに書き換えが要るこの世界では、学び直しを邪魔する側に働く。
  （A がいつもの世界で、B がときどきの寄り道なら働く。世界の選び方で結論が変わる）
- **容量の問題**：2タップの予測器は、周期を1つしか表せない（係数が周期で決まる）。1つの予測器に A と B を両方しまうことはできない
- 候補（どちらも新しい状態と規則）：

    （安い式：J(u) = uᵀRu − 2uᵀr ＋ S。S は s² の痕跡で、足すのは1つだけ）。十分に合えば、それを書く（思い出す）。
    合わなければ、いまの書き換え（最小二乗）。局所で閉じ、乱数を使わない
  - **M2：予測器の容量を増やす**（4タップ）。4タップなら、2つの周期を同時に当てられる（特性多項式の根を両方に置ける）。
    記憶＝長い痕跡（遅い統計）、硬さ＝その精度。線形の予測器では、EWC の硬さ（フィッシャー情報）は入力の2次の統計 R/σ² そのものなので、
    「遅い痕跡」と「硬さ」は同じものになり、きれい。**ただし穴がある**：2つの周期を同時に当てる係数は大きく、入力のノイズを大きく増やす
    （12 と 24 なら当てられない誤差が2タップの約3倍）。ノイズのある世界では、両方を少しずつ外す妥協になる。予測器の形（そろえる軸）も動かす
- どの候補でも、**覚える（いつ、何を保存するか）**、**思い出す（比べて選ぶ）**、**忘れる（入れ替え、減衰）**の3つを決める必要がある

### 7.2 結果（2026-09-30。`runs/precheck_headroom/`、EXPERIMENTS.md）

**事前の読み方どおりの判定**
- ノイズ0.02：戻りの切り替えの余地の最小は2.6ナット/回（12/20 の組の2回目の A→B）→ **中間（そうの判断）**

  ノイズの乗った入力から予測する最良の係数ではない（最小二乗で学んだ床の係数のほうが当たることがある）。**ノイズ0.04 では、正確な係数は天井にならない**
- M1 の思い出す確かめ：**穴**。C の時期に、発火の29〜33% で間違った保存先を書いた（基準は2割以上で穴）。B の時期にも、発火の約45% で古い保存先（A）を書いた
  （切り替えの直後は、最近の痕跡の大半がまだ古いパターンなので、古い保存先が「十分に合う」と判定される）

**予想していなかったこと：床は、2回目以降の切り替えで学ぶのをやめる（慣れ）**
- 床は最初の切り替え（A→B）では1セルあたり3.2〜3.9回発火して学び直すが、**そのあとの切り替えでは0.01〜0.45回しか発火せず、B の係数のまま動かなくなる**

### 12.7 思い出し方（Claude の案。そうの判断待ち。模擬で選ぶ）

**穴（§7.2）**：前の模擬（M1）は、驚いて発火したとき、最近の痕跡の上でいちばん合う保存先が「十分に合う」（当てはまりの差 ≤ 6σ²）なら思い出した。

初めてのパターンでは約3割で間違った保存先を書いた

**決まっていること（候補に共通）**
- **いつ**：驚いて発火したとき。思い出しは、その発火の書き換え（床の最小二乗の一歩）の代わりに、保存先の係数をそのまま書く。**同じ1回の出来事なので、書き込みは1回**（内訳で「思い出し」として数える。二重に数えない）
- **材料**：最近の痕跡 R・r（床の最小二乗と同じ約10ステップ）。長い痕跡は使えない：眠る段の決まりで、驚いて発火した瞬間に0 に戻るので、戻す前なら古いパターンだけ、戻した後ならこの1歩だけが入っていて、どちらも新しいパターンと比べる材料にならない
- **物差し**：D(u) = (u − w_ls)ᵀ R (u − w_ls)（最近の材料の上で、保存先 u が、いま解いた最小二乗の解 w_ls よりどれだけ合わないか。J(u) − J(w_ls) にあたる）。基準は6σ²（しまうときと同じ物差しと数）
- σ₄ には触らない（係数が正確なら、σ₄ は移動平均で自然に戻る。§9.4 の神様の版 ②'）。思い出した保存先は「使った」として、忘れ方の数えを0 に戻す
- 比べた保存先の数（埋まっている数）を、驚きの発火ごとに記録する（10.4）

**候補**
- **(お1) 前の模擬と同じ**：いちばん合う保存先 u* が D(u*) ≤ 6σ² なら思い出す（穴があると分かっている。比べるための参考）
- **(お2) いまの係数より、はっきり合うものだけ思い出す**：D(u*) ＋ 6σ² ≤ D(w_今)（w_今 は、驚いた瞬間の、書き換える前の係数）。
  （2026-10-02 の直し：最初に書いた (お2) は「D(u*) ≤ 6σ² かつ」も含んでいたが、チャットでの説明は「はっきり合う」だけだった。そうの読みに合わせて (お2) を「はっきり合う」だけにし、両方を (お3) にした）
