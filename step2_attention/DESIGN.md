## 0. この Step で確かめたいこと

各セルが「次に自分の場所で感じる値」を予測し、自信度（σ）もいっしょに出す。驚き（z²）が大きいときだけ発火して、予測器を書き換える。

1. **σ の地図**：予測できる場所（波）では σ が小さく、予測できない場所（ノイズ）では σ が大きくなる（自信度＝注意）
2. **静けさ**：学び終わったら、波の区域でもノイズの区域でも発火がほぼ0になる（ノイジーTV問題を起こさない）
3. **驚きの波と学び直し**：世界が変わる（波の周期が変わる）と、変わった場所だけで発火が起き、学び直して、また静かになる。
   新しい周期は波として左から届くので、驚き（発火）も波のように広がるはず

## 1. 世界の作り方

```
 x=0（光源）→→→→→→→→→→→→→→→→→→→→→→→→ x=31
 ┌──────────────────────────────────┐
 │  波（正弦波の帯が右へ1セル/ステップで流れる）  │
 │                                              │
 │                              ┌────────┐│
 │                              │ ノイズ  ││  ← 右下 8×8（x≥24, y≥24）
 │                              │（一様乱数）││
 └──────────────────────────────┴────────┘┘
```

- 格子 32×32。すべてのセルが生きている（Step 1 のような成長・生死はない）。各セルはセンサーで今の値 s ∈ [0,1] を感じる
- **波**：左端の光源が周期 P で振動し、その値が右へ1セル/ステップで流れる。
  - 光源の位相 φ を毎ステップ 2π/P ずつ進める（φ ← φ + 2π/P）。s(x, t) = 0.5 + 0.4·sin(φ(t − x)) ＋ センサーのノイズ N(0, 0.02²)
  - **周期を変えるときは P だけを変え、φ はつなげたままにする**（位相が飛ぶと、周期の変化とは別の驚きが混ざるため）
  - 新しい周期は、光源から右へ波として届く。列 x に届くのは、変えた時刻 t_c から x ステップ後
- **ノイズの区域**：右下 8×8。毎ステップ、一様乱数 U[0,1] を出す（波は届かない）
  - 一様乱数の最適な予測は μ=0.5、σ=0.289。このとき z² =（誤差/σ）² は最大3を超えない
  - より厳しい版として、ガウスのノイズ（z² の尾が長い）も後で試す
- 周期の分布：学習では P を 10〜30 から毎回選び、途中で P を変える回も混ぜる（DNA が「書き換え方」を学べるように）。
  評価では、学習で見ていない組み合わせ（例：P=12 → 24）も使う
- 帯について：CLAUDE.md の「光の帯」は、まず正弦波（やわらかい帯）にする。2つ前までの値の線形予測で正確に当てられるので、
  予測器の出来ではなく注意と発火の仕組みを確かめられる。くっきりした帯（パルス）は後で試す

## 2. 予測と自信度の出し方（レビュー②の (a) 案）

**予測は毎ステップの安い読み出し、発火＝書き換え**。

- 各セルは、自分用の小さな線形予測器（速い重み）と自信度を持つ：
  - μ(t+1) = w₁·s(t) ＋ w₂·s(t−1) ＋ b（重み3つ。発火したときに書き換える）
  - σ（最近の誤差の大きさ。毎ステップの安い式で追いかける。3章の「決めてもらうこと①」）
- 正弦波なら、この予測器で正確に当てられる：s(t+1) = 2cos(ω)·s(t) − s(t−1) ＋ 定数。重みは周期で決まるので、**周期が変わると書き換えが要る**
- ただし、センサーのノイズ（0.02）は予測器の入力にも乗るので、当てられない誤差が残る：
  標準偏差 0.02·√(2 ＋ 4cos²ω) ≈ **0.04〜0.05**（周期10〜30）。波の区域の σ は、下限の0.02ではなく、このあたりに落ち着くはず
- **予測器が読むのは自分の過去だけ（近所は読まない）**。理由：波は1セル/ステップで流れるので、次の自分の値＝今の左隣の値。
  予測器が近所を読めると「左隣を写す」だけで当たり、周期を変えても誰も驚かない（2c が成り立たない）。
  近所を読めるようにするなら、2c は周期ではなく速さを変える実験になる（今回は採らない）
- 近所の情報は、**発火したときに DNA が 3×3 の近所の状態（近所の予測器の重みを含む）を知覚する**形で使う。
  近所がもう学び直していれば、その重みを借りて速く学び直せる（学習の伝播）かもしれない。これは観察したいこと

### 毎ステップの安い計算（全セル、固定の式）
1. 世界から s(t) を受け取り、前のステップの予測との誤差 e = s(t) − μ(t) と z² = e²/σ² を計算する
2. 痕跡（トレース）を足す：tr_w ← γ·tr_w ＋ e·f(t−1)（f は予測に使った特徴 [s(t−1), s(t−2), 1]）。γ = 0.9（案）
3. 驚きの濃度（z² の移動平均）を更新する：c ← 0.9·c ＋ 0.1·z²（直近約10ステップ）
4. 自信度を更新する（案 (B)）：v ← 0.99·v ＋ 0.01·e²、σ = max(σ_min, √v)（直近約100ステップの誤差の大きさ）
5. 予測器を読んで、次の予測 μ(t+1) を出す

σ の時間の長さ（約100ステップ）は、濃度（約10ステップ）より長くしておく。世界が変わった直後は、誤差が急に大きくなっても
σ はすぐには追いつかないので z² が大きいままになり、予測器を学び直すまで発火が続く。学び直すと誤差が下がって静かになり、
σ もゆっくり元に戻る

### 発火したときだけの高い計算
1. 3×3 の近所の状態を知覚する（予測器の重み、σ、痕跡、濃度、隠れの状態）
2. DNA（全セル共通の小さな MLP）が、書き換えの「ゲート」を出す：
   学習率 η（0〜1）、重みの減衰 g（0〜1、1なら減衰なし）、隠れの状態の変化量
3. 書き換える（どれも1回の大きさに上限をつける。Step 1 の tanh の教訓）：
   - 重み：w ← g·w ＋ tanh(η·tr_w)　（デルタ則＋ゲートつき減衰。CLAUDE.md の速い重みの形。1回で各重みが動くのは ±1 以内）
   - 隠れの状態：h ← h ＋ tanh(Δh)
4. 痕跡を0に戻し、濃度を0に戻し、1ステップ休む（不応期）

DNA が学ぶのは「いつ痕跡を信じて、どれだけ書き換えるか」で、書き換えの向き（デルタ則）は固定。CLAUDE.md の二層構造
（DNA は書き換え方を学び、速い重みは使いながら書き換わる）そのもの。

## 3. 驚き、σ の下限、発火のしきい値

- **学習の損失（DNA を育てる）**：NLL =（s − μ）²/(2σ²) ＋ log σ（全セル・全ステップの平均）
- **発火の引き金**：z² を溜めた濃度 c（直近約10ステップの z² の平均）がしきい値 θ を超えたら発火
  - θ = 4（案）：自信度が合っていれば z² の平均は1なので、c が4を超えるのはまれ。自信満々で外すと z² は数百になり、すぐ超える
  - 引き金は固定の式で、学習しない（ストレートスルー推定も使わない）。発火は驚きで決まる（原則4）
- **σ の下限**：σ_min = 0.02（センサーのノイズと同じ）。この世界では当てられない誤差（約0.045）が下限より大きいので、
  落ち着いた σ は下限より上にくる。下限が効くのは、学び始め（v₀ = σ_min²）と、センサーのノイズをなくした世界（σ→0 で NLL が発散する）
- **σ の初期値は下限と同じにする**（σ₀ = σ_min、v₀ = σ_min²）。高く始めると、予測が外れていても z² が小さいまま発火せず、
  いつまでも学ばない（Step 1 で d_bias=2 から始めて台地から出られなかったのと同じ落とし穴）。
  下限から始めれば、最初は全員が発火して学び、自信度が合ってくると静かになる
- **λ（発火のペナルティ）は0を基本にする**。Step 2 では発火は学習しない引き金で決まり、静けさは自信度が合うことから来るので、
  ペナルティは要らないはず。λ>0 は比べる版として試す
- 見張り：落ち着いた時期の z² の平均を区域ごとに記録する（(B) なら σ は DNA が決めないので「ずる」はできないが、確かめとして残す）

### 決めてもらうこと①：σ を、発火のときに書き換えるか、毎ステップの安い式で追いかけるか
- **(A) 発火のときだけ書き換える**：「発火＝書き込み」がいちばんきれい。**ただし、仕組みの上でうまく働かない**：
  - 発火するのは濃度（z² の平均）が4を超えたときだけなので、そのとき σ の書き換えの向きは、ほぼ必ず「上げる」になる。
    **σ は上がる一方で、下がる機会がない**（自信を取り戻すには、驚いていないときに書き換える必要がある）
  - 学び始めに σ が膨らむと z² が小さくなり、予測器の重みを覚える前にセルが黙ってしまう
  - 直すには、驚いていなくてもときどき起きて σ を見直す仕組み（Step 1 の目覚ましのようなもの）が別に要る
- **(B) 毎ステップの安い式で追いかける（上の設計）**：v ← 0.99·v ＋ 0.01·e²、σ = max(σ_min, √v)。
  - 自信度は必ず合う（落ち着けば z² の平均は1前後）。σ は DNA が決めないので「σ を大きめにして発火を避けるずる」もできない
  - 引き金は「最近の誤差のふつうの大きさに比べて、急に外れたか」になる。変化の検出そのもの
  - 代わりに、σ は毎ステップ書き換わる。ただしこれは濃度 c と同じ「安い移動平均」で、学んだ重みの書き換えではない。
    CLAUDE.md の計算の会計に「σ は毎ステップの安い移動平均」と書き足すことになる
- 私の案：**(B)**。自信度の範囲は [0.5, 1.5]、しきい値 θ=4 のままでよい

## 4. 計算の会計（原則7）

| いつ | してよいこと | Step 2 での中身 |
|---|---|---|
| 毎ステップ（全セル） | 固定の安い式だけ | 予測器の読み出し（μ）、誤差と z² の計算、痕跡の足し算、濃度の更新、σ の移動平均の更新（案 (B)）、不応期 |
| 発火したときだけ | 知覚＋DNA＋書き込み | 近所の知覚、DNA の MLP、予測器の重み・隠れの状態の書き換え |

- 発火回数は、区域ごと（波・ノイズ）に数える
- 予測器の読み出しは、インメモリ計算のハードなら「重みを読むだけ」の安い計算。書き込み（発火）が高い計算にあたる

## 5. DNA の学習

- 誤差逆伝播で、ロールアウト（数百ステップ）を通して学ぶ。損失は NLL の平均（λ=0）
- プールで学ぶ（Step 1 と同じ）：セルの状態（予測器の重み、σ の移動平均、痕跡、濃度、隠れの状態）と世界の状態（光源の位相と周期）をプールに持ち、
  続きから回す。ときどき世界を新しくし（周期を選び直し、予測器を初期化）、ときどき途中で周期を変える
- 2b は 2a の DNA から始めるか、ゼロから学び直す。2a の DNA は「毎ステップ少しずつ書き換える」ゲートに慣れているので、
  まれに書き換える 2b ではそのままでは合わない（学び直しが要る）
- Step 1 から持ち越すもの：1回の書き換えの上限（tanh）、勾配に無限大や nan が混ざった回は更新を飛ばす守り（回数を記録）、
  良い重みを残す仕組み（NLL と発火数のパレートの前線、質の下限つき）、設定の先書き、シード固定

## 6. 段取り：2a → 2b → 2c（一度に1つずつ新しくする）

| 段 | 新しくすること | 見ること |
|---|---|---|
| **2a** | 予測器と σ（全員が毎ステップ書き換える。発火の判断なし） | σ の地図が正しく出るか、自信度が合うか、NLL が下がるか |
| **2b** | z² の引き金で発火させる | 学び終わったら両区域で発火がほぼ0か、σ の地図と自信度を保つか |
| **2c** | 途中で光源の周期を変える（学習にも混ぜる） | 変わった場所だけが発火し、学び直して、また静かになるか |

### 評価のプロトコル（案）
- 0〜400：学ぶ（予測器は0、σ は下限から始める）
- 400〜800：落ち着く（静けさを測る）
- 800：光源の周期を変える（例：P=12 → 24、位相はつなげたまま）
- 800〜1400：学び直す
- すべての指標を、波・ノイズの区域ごとに出す。タイミングのずれ 0／0.1／0.3 でも評価する（Step 1 と同じ）
- 2c の指標は、**新しい波がその列に届いた時刻（t_c ＋ x）から測る**。変えた時刻から測ると、波が届くまでの時間と
  セルの反応の時間が混ざるため

## 7. 事前の成功条件（案）

どれもシード2本以上でそろえる。Step 2 の卒業は、Step 1 と同じく「4本中3本以上」で 2b と 2c の条件を満たすこと（案）。

### 2a
- σ の地図：波の区域の σ の中央値 ≤ 0.06（当てられない誤差 約0.04〜0.05 の近く）、
  ノイズの区域の σ の中央値が 0.25〜0.33（一様乱数の標準偏差 0.289 の近く）。2つの区域で σ が5倍以上違う
- 自信度：落ち着いた時期（400〜800）の z² の平均が、どちらの区域も [0.5, 1.5]
- NLL：波の区域で、当てられない誤差（約0.045）の正規分布の NLL の近くまで下がる

### 2b
- 落ち着いた時期の発火率が、どちらの区域も **1%（セル×ステップあたり）以下**
- 波の区域の NLL が、2a より 0.1 ナット以上悪くならない
- 自信度：z² の平均が、どちらの区域も [0.5, 1.5]
- σ の地図は 2a と同じ条件を満たす。**一様ノイズでは、σ が0.25以上に上がっていれば z² は4を超えられないので、
  ノイズの区域が静かなことは発火数だけでは確かめられない。確かめるのは σ の地図**
- ヌル対照（下）より、「NLL と発火数」の曲線で左下にある

### 2c
- 反応：新しい波が届いてから10ステップ以内に、波の区域の9割以上の列で発火が起きる
- 局所性：ノイズの区域の発火率は、周期を変えたあとも1%以下のまま
- 学び直し：新しい波が届いてから300ステップ以内に、各列の NLL が変える前の水準（＋0.1 ナット以内）に戻る
- 静けさに戻る：学び直したあと、波の区域の発火率が1%以下に戻る
- 観察したいこと（成功条件ではない）：**新しい波が届く前に学び直すセルが出たら**、DNA が近所の書き換えた重みを読んで
  借りている（学習の伝播）ということ。驚きの波と学び直しの波が、どう重なるかを見る

## 8. ヌル対照

| 対照 | 中身 | 何を確かめるか |
|---|---|---|
| **DNA なし（いちばん大事）** | ゲート（η、g）を手で決めた固定のデルタ則。同じ z² の引き金、同じ σ の移動平均 | DNA が何かを足しているか。これで 2b・2c を満たせるなら、DNA の価値は「効率」でしか測れない（Step 1 で周期2の時計が Run B の質を説明したのと同じ役） |
| 密な書き換え（2a） | 全員が毎ステップ書き換える | 質と学び直しの速さの上限 |
| 一定周期の時計 | k ステップごとに全員が書き換える | 発火数を変えたときの曲線 |
| サイコロ | 同じ平均発火率でランダムに書き換える | 同じ発火数で、驚きで選ぶ意味があるか |
| 時限停止 | 400 まで密に書き換え、以後は書き換えない | 2c で学び直せないことの確認（落ち着いた時期の下限） |
| **NLL をそのまま引き金にする** | z² ではなく NLL（log σ 込み）を溜める | ノイジーTV問題。ノイズの区域が発火し続けるはず（レビュー①の直接の確かめ） |
| **σ を固定する** | σ = σ_min のまま追いかけない | どちらの区域でも z² が大きいままになり（波でも当てられない誤差0.045が下限0.02より大きい）、発火し続けるはず（自信度＝注意の確かめ） |

DNA なしのゲートは、公平にするため小さな格子探索で一番良い値を選ぶ。
