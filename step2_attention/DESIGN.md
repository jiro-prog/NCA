## 0. この Step で確かめたいこと

各セルが「次に自分の場所で感じる値」を予測し、自信度（σ）もいっしょに出す。驚き（z²）が大きいときだけ発火して、予測器を書き換える。

1. **σ の地図**：予測できる場所（波）では σ が小さく、予測できない場所（ノイズ）では σ が大きくなる（自信度＝注意）
2. **静けさ**：学び終わったら、波の区域でもノイズの区域でも発火がほぼ0になる（ノイジーTV問題を起こさない）
3. **驚きの波と学び直し**：世界が変わる（波の周期が変わる）と、変わった場所だけで発火が起き、学び直して、また静かになる。
   新しい周期は波として左から届くので、驚き（発火）も波のように広がるはず

## 1. 世界の作り方

```
 x=0（光源）→→→→→→→→→→→→→→→→→→→→→→→→ x=31
 ┌──────────────────────────────────┐
 │  波（正弦波の帯が右へ0.25列/ステップで流れる）  │
 │                                              │
 │                              ┌────────┐│
 │                              │ ノイズ  ││  ← 右下 8×8（x≥24, y≥24）
 │                              │（一様乱数）││
 └──────────────────────────────┴────────┘┘
```

- 格子 32×32。すべてのセルが生きている（Step 1 のような成長・生死はない）。各セルはセンサーで今の値 s ∈ [0,1] を感じる
- **波**：左端の光源が周期 P で振動し、その値が右へ流れる。**速さは v = 0.25 列/ステップ（4ステップに1列）**（2026-09-29 に決定）
  - 光源の位相 φ を毎ステップ 2π/P ずつ進める（φ ← φ + 2π/P）。列 x の値は、光源の x/v ステップ前の値：
    s(x, t) = 0.5 + 0.4·sin(φ(t − x/v)) ＋ センサーのノイズ N(0, 0.02²)
  - **周期を変えるときは P だけを変え、φ はつなげたままにする**（位相が飛ぶと、周期の変化とは別の驚きが混ざるため）
  - 新しい周期は、光源から右へ波として届く。列 x に届くのは、変えた時刻 t_c から x/v ステップ後
  - v = 0.25 なら：前線は124ステップで右端（x=31）に届く。800に変えれば、x=24（ノイズの区域の手前）に896、右端に924。
    学び直しの窓（届いてから300ステップ）は1224で終わり、評価の1400に収まる。波長は 0.25·P ＝ 2.5〜7.5列
  - **なぜ遅くするか**（2章「学習の伝播と、世界の速さの制約」）：最初の案の v = 1 だと、学習の伝播は理屈の上で起こりえない
- **ノイズの区域**：右下 8×8。毎ステップ、一様乱数 U[0,1] を出す（波は届かない）
  - 一様乱数の最適な予測は μ=0.5、σ=0.289。このとき z² =（誤差/σ）² は最大3を超えない
  - より厳しい版として、ガウスのノイズ（z² の尾が長い）も後で試す
- 周期の分布：学習では P を 10〜30 から毎回選ぶ。**ただし 18〜22 は学習で見せない**（内側の見せない周期）。
  途中で P を変える回も混ぜる（DNA が「書き換え方」を学べるように）。
  評価では、学習で見せた周期（例：P=12 → 24）に加えて、**見せない周期**でも確かめる（7章）：
  内側の P=20（18〜22 の穴の中）と、外側の P=36（学習の範囲の外）
- 帯について：CLAUDE.md の「光の帯」は、まず正弦波（やわらかい帯）にする。2つ前までの値の線形予測で正確に当てられるので、
  予測器の出来ではなく注意と発火の仕組みを確かめられる。くっきりした帯（パルス）は後で試す

## 2. 予測と自信度の出し方（レビュー②の (a) 案）

**予測は毎ステップの安い読み出し、発火＝書き換え**。

- 各セルは、自分用の小さな線形予測器（速い重み）と自信度を持つ：
  - μ(t+1) = w₁·s(t) ＋ w₂·s(t−1) ＋ b（重み3つ。発火したときに書き換える）
  - σ（最近の誤差の大きさ。毎ステップの安い式で追いかける。3章の「決めてもらうこと①」）
- 正弦波なら、この予測器で正確に当てられる：s(t+1) = 2cos(ω)·s(t) − s(t−1) ＋ 定数。重みは周期で決まるので、**周期が変わると書き換えが要る**
- ただし、センサーのノイズ（0.02）は予測器の入力にも乗るので、当てられない誤差が残る：
  標準偏差 0.02·√(2 ＋ 4cos²ω) ≈ **0.04〜0.05**（周期10〜30）。波の区域の σ は、下限の0.02ではなく、このあたりに落ち着くはず
- **予測器が読むのは自分の過去だけ（近所は読まない）**。理由：波は一定の速さで流れるので、次の自分の値は左隣の少し前の値と同じ
  （v=1 なら今の左隣、v=0.25 なら左隣の4ステップ前）。予測器が近所を読めると「左隣を写す」だけで当たり、
  周期を変えても誰も驚かない（2c が成り立たない）。近所を読めるようにするなら、2c は周期ではなく速さを変える実験になる（今回は採らない）
- 近所の情報は、**発火したときに DNA が 3×3 の近所の状態（近所の予測器の重みを含む）を知覚する**形で使う。
  近所がもう学び直していれば、その重みを借りて速く学び直せる（学習の伝播）。これを 2c の成功条件の中心に置く（7章）

### 学習の伝播と、世界の速さの制約（光円錐）
- **情報は、1ステップに多くて1列しか進めない**：発火したセルが近所（3×3）を読むことでしか伝わらないため（原則2の「局所」を数にしたもの）。
  さらに不応期でセルは多くて2ステップに1回しか発火しないので、発火の鎖で運ばれる速さは **0.5〜1列/ステップ**（発火のずれ方しだい）
- **伝達は、驚いて発火しているセルしか通れない**：前線より先のセルは古い周期のままで静か（発火しない）なので、何も受け取れない。
  学習の伝播は、**前線の後ろ**で、いま驚いたセルが、自分より長く学び直している左隣の重みを読む、という形でしか起きない
- **v = 1（最初の案）だと起こりえない**：変化も1列/ステップで届くので、左端の列が学び直しを終えた重みが列 x に届くのは、
  列 x が自分で学び直し終える時刻と同じ（「前線に届いてから T ステップ後」）。借りる意味がない
- **v < 1 なら起こりうる**：左隣は、自分より (1/v − 1) ステップ長く学び直している。v = 0.25 なら3ステップ分先を行っている。
  右の列ほど、左から伝わってきた「先を行く重み」を受け取れるので、**右の列ほど学び直しの発火が少なくなる**はず。
  v を遅くするほど、この差は大きくなるはず。0.5 は不応期を考えると際どいので、0.25 にした
- **リスク：地形が許しても、DNA が「借りる」ことを学ぶ保証はない**。最初に驚いたときに「自分の痕跡より左隣の重みを信じる」ゲートを
  DNA が出す必要がある。学習の分布に、この速さでの周期の変化が入っていて、借りたほうが NLL が早く下がるときに、はじめて学ばれる

### 毎ステップの安い計算（全セル、固定の式）
1. 世界から s(t) を受け取り、前のステップの予測との誤差 e = s(t) − μ(t) と z² = e²/σ² を計算する
2. 痕跡（トレース）を足す：tr_w ← γ·tr_w ＋ e·f(t−1)（f は予測に使った特徴 [s(t−1), s(t−2), 1]）。γ = 0.9（案）
3. 驚きの濃度（z² の移動平均）を更新する：c ← 0.9·c ＋ 0.1·z²（直近約10ステップ）
4. 自信度を更新する（案 (B)）：v ← 0.99·v ＋ 0.01·e²、σ = max(σ_min, √v)（直近約100ステップの誤差の大きさ）
5. 予測器を読んで、次の予測 μ(t+1) を出す

σ の時間の長さ（約100ステップ）は、濃度（約10ステップ）より長くしておく。世界が変わった直後は、誤差が急に大きくなっても
σ はすぐには追いつかないので z² が大きいままになり、予測器を学び直すまで発火が続く。学び直すと誤差が下がって静かになり、
σ もゆっくり元に戻る

### 発火したときだけの高い計算
1. **3×3 の近所の生の値を知覚する**：9か所それぞれの状態（予測器の係数 w₁・w₂・b、σ、痕跡、濃度、隠れの状態、最近のセンサーの値）を、
   混ぜずにそのまま DNA の入力にする。Step 1 のソーベルの知覚（自分の値と左右・上下の差）は使わない（下の「確認」）
2. DNA（全セル共通の小さな MLP）が出すもの：
   - ゲート：学習率 η（0〜1）、重みの減衰 g（0〜1、1なら減衰なし）
   - **係数の補正 Δw（3つ）**：近所の係数を借りるための自由な項
   - 隠れの状態の変化量
3. 書き換える（どれも1回の大きさに上限をつける。Step 1 の tanh の教訓）：
   - 重み：**w ← g·w ＋ tanh(η·tr_w ＋ Δw)**　（デルタ則＋ゲートつき減衰に、DNA の補正を足したもの。1回で各重みが動くのは ±1 以内）
   - 隠れの状態：h ← h ＋ tanh(Δh)
4. 痕跡を0に戻し、濃度を0に戻し、1ステップ休む（不応期）

DNA が学ぶのは「いつ痕跡を信じて、どれだけ書き換えるか」と「近所の係数をどれだけ借りるか」。書き換えの基本の向き（デルタ則）は固定。
CLAUDE.md の二層構造（DNA は書き換え方を学び、速い重みは使いながら書き換わる）そのもの。
「DNA なし」の対照は、ゲートを手で決め、補正 Δw は0（近所を使わない）

### 確認：発火したセルの DNA は、近所の予測器の係数そのものを知覚できるか（2026-09-29）
最初の草案のままでは、**借りようがなかった**。理由は2つあり、上のとおり直した：
- **知覚の形**：Step 1 と同じソーベルの知覚だと、1つのチャンネルについて「自分の値・左右の差・上下の差」の3つしか見えず、
  左隣の値を単独では取り出せない（左と右が混ざった差になる）。学習の伝播では「自分より先を行く左隣の係数」を借りたいので、
  9か所の生の値をそのまま見せる
- **書き込みの形**：草案の書き換えは w ← g·w ＋ tanh(η·tr_w) で、DNA が出せるのは学習率と減衰のゲートだけだった。
  近所の係数を知覚できても、それを自分の係数に書き込む道がない。補正 Δw を足して、たとえば「左隣の係数 − 自分の係数」を
  DNA が出せるようにした（1回で ±1 以内なので、係数の差が大きいと何回かに分けて借りる）
- 実装したら、テストで確かめる：DNA の入力に左隣の係数がそのまま入っていること、補正で係数が左隣の値に近づけること

### 穴1：ノイズ0.02では、周期を変えても驚かない（世界の問題。書き換え方や DNA とは関係ない）
- 2つ前までの線形予測は「今の動きを延ばす」予測なので、ゆっくりした波（1周期に10〜30ステップ）では、周期が変わっても予測はあまり外れない。
  外れの大きさは √2·0.4·|cos ω₂ − cos ω₁|（12→24 で約0.057）で、当てられない誤差（約0.045）と同じくらいしかない
- 学び終えた予測器で、変えた直後の z² の平均は 1.0〜3.4。しきい値4に届かない（θ=2 でも、10ステップ以内に反応するのは3〜5割）
- ノイズ0.005（σ の下限も0.005）なら、12→24 で27、12→20 で20、12→36 で37、24→12 で23。**ただし 24→36 は1.8のまま**
  （cos ω が0.02しか変わらない）。外側の見せない周期のテストは、24→36 を見えるもの（12→36 など）に替える必要がある

### 穴2：「DNA なし」の書き換えは、驚きが続く間に学び終えられず「あきらめる」（仕組みの問題）
- σ は誤差の移動平均なので、誤差が急に大きくなると **約25ステップ**で追いつき、z² が1前後に戻る
  （「約100ステップ」は σ が落ち着くまでの長さで、驚きが続くのはその4分の1くらい）。その間の発火は1セル3〜7回
- 痕跡つきデルタ則は、1回の発火で小さな一歩しか進めない（s(t) と s(t−1) がほぼ同じ向きなので、周期を表す向きの学びがとくに遅い）。
  数回では学べず、**当てられない誤差の5〜16倍の誤差のまま静かになる**。学習率をどう選んでも、σ の窓を約1000にしても同じ
- 学び終えた状態から始めても、学び直しで同じことが起きる（ほぼ全員があきらめる）。最初だけ密に学ばせても直らない
- **意味：いちばん大事な対照（DNA なし）が、このままでは「勝って当然の相手」になる**。DNA は最近のセンサーの値を生で見るので、
  3つの連続した値から周期がわかり、1〜2回の発火で正しい係数を書ける可能性がある（DNA がだめとは限らない）

## 3. 驚き、σ の下限、発火のしきい値

- **学習の損失（DNA を育てる）**：NLL =（s − μ）²/(2σ²) ＋ log σ（全セル・全ステップの平均）
- **発火の引き金**：z² を溜めた濃度 c（直近約10ステップの z² の平均）がしきい値 θ を超えたら発火
  - θ = 4（案）：自信度が合っていれば z² の平均は1なので、c が4を超えるのはまれ。自信満々で外すと z² は数百になり、すぐ超える
  - 引き金は固定の式で、学習しない（ストレートスルー推定も使わない）。発火は驚きで決まる（原則4）
- **σ の下限**：σ_min = 0.02（センサーのノイズと同じ）。この世界では当てられない誤差（約0.045）が下限より大きいので、
  落ち着いた σ は下限より上にくる。下限が効くのは、学び始め（v₀ = σ_min²）と、センサーのノイズをなくした世界（σ→0 で NLL が発散する）
- **σ の初期値は下限と同じにする**（σ₀ = σ_min、v₀ = σ_min²）。高く始めると、予測が外れていても z² が小さいまま発火せず、
  いつまでも学ばない（Step 1 で d_bias=2 から始めて台地から出られなかったのと同じ落とし穴）。
  下限から始めれば、最初は全員が発火して学び、自信度が合ってくると静かになる
- **λ（発火のペナルティ）は0を基本にする**。Step 2 では発火は学習しない引き金で決まり、静けさは自信度が合うことから来るので、
  ペナルティは要らないはず。λ>0 は比べる版として試す
- 見張り：落ち着いた時期の z² の平均を区域ごとに記録する（(B) なら σ は DNA が決めないので「ずる」はできないが、確かめとして残す）

### 決めてもらうこと①：σ を、発火のときに書き換えるか、毎ステップの安い式で追いかけるか
- **(A) 発火のときだけ書き換える**：「発火＝書き込み」がいちばんきれい。**ただし、仕組みの上でうまく働かない**：
  - 発火するのは濃度（z² の平均）が4を超えたときだけなので、そのとき σ の書き換えの向きは、ほぼ必ず「上げる」になる。
    **σ は上がる一方で、下がる機会がない**（自信を取り戻すには、驚いていないときに書き換える必要がある）
  - 学び始めに σ が膨らむと z² が小さくなり、予測器の重みを覚える前にセルが黙ってしまう
  - 直すには、驚いていなくてもときどき起きて σ を見直す仕組み（Step 1 の目覚ましのようなもの）が別に要る
- **(B) 毎ステップの安い式で追いかける（上の設計）**：v ← 0.99·v ＋ 0.01·e²、σ = max(σ_min, √v)。
  - 自信度は必ず合う（落ち着けば z² の平均は1前後）。σ は DNA が決めないので「σ を大きめにして発火を避けるずる」もできない
  - 引き金は「最近の誤差のふつうの大きさに比べて、急に外れたか」になる。変化の検出そのもの
  - 代わりに、σ は毎ステップ書き換わる。ただしこれは濃度 c と同じ「安い移動平均」で、学んだ重みの書き換えではない。
    CLAUDE.md の計算の会計に「σ は毎ステップの安い移動平均」と書き足すことになる
- 私の案：**(B)**。自信度の範囲は [0.5, 1.5]、しきい値 θ=4 のままでよい → **(B) に決定**（2026-09-28）

### (B) の弱点：学び直せないセルは「あきらめて」静かになる
σ は約100ステップで誤差の大きさに追いつくので、**100ステップ以内に予測器を学び直せないセルは、σ が上がって z² が1前後に戻り、
予測は外れたまま静かになる**（新しい世界に慣れて、あきらめる）。そこで：
- 2c では「波の区域で、σ が高いまま下がらないセル」の数を測る（7章）
- 2b で、学び直しにかかる時間を先に測る。**100ステップより十分短くなければ（案：学び直しにかかる時間の上位10%が30ステップを超えたら）、
  2c の前に σ の窓を長くする**（案：学び直しにかかる時間の上位10%の3倍以上）

### 「自信度の範囲 [0.5, 1.5]」とは
- σ は「自分の予測は、ふだんこのくらい外れる」という自己申告
- 申告が正直なら、実際の誤差を σ で割って2乗したもの（z²）は、平均するとちょうど1になる
- 平均が1より小さい：実際より大げさに「外れる」と言っている（自信がなさすぎる、鈍感）。1より大きい：実際より小さく言っている（自信過剰）
- [0.5, 1.5] は、**σ が本当の外れ具合の約0.82倍〜1.41倍に収まっていればよい**という意味（z² の平均 = (本当の外れ具合 ÷ σ)²）

## 5. DNA の学習

- 誤差逆伝播で、ロールアウト（数百ステップ）を通して学ぶ。損失は NLL の平均（λ=0）

  セルの反応の時間が混ざるため

## 7. 事前の成功条件（案）

成功条件は3つの枠に分ける（2026-09-29、そうの判断）。**学習の伝播は「DNA の価値の証明」として別枠にし、伝播が起きなくても卒業できる**。
どれもシード2本以上でそろえる。数字はすべて案。

### 7.1 途中の段の確かめ（2a・2b。卒業の前提）

**2a**
- σ の地図：波の区域の σ の中央値 ≤ 0.06（当てられない誤差 約0.04〜0.05 の近く）、
  ノイズの区域の σ の中央値が 0.25〜0.33（一様乱数の標準偏差 0.289 の近く）。2つの区域で σ が5倍以上違う
- 自信度：落ち着いた時期（400〜800）の z² の平均が、どちらの区域も [0.5, 1.5]
- NLL：波の区域で、当てられない誤差（約0.045）の正規分布の NLL の近くまで下がる

**2b**
- 落ち着いた時期の発火率が、どちらの区域も **1%（セル×ステップあたり）以下**
- 波の区域の NLL が、2a より 0.1 ナット以上悪くならない
- 自信度：z² の平均が、どちらの区域も [0.5, 1.5]。σ の地図は 2a と同じ条件を満たす
- **ノイズの区域の静けさは「設計の保証」として記録し、「学習の成果」には数えない**：一様ノイズでは z² に上限があり
  （σ が0.25以上なら z² は4を超えられない）、σ が上がればノイズの区域は仕組みの上で発火できない。
  ノイズの区域について学習の成果として確かめるのは、σ の地図（σ がそこまで上がるか）だけ。ガウスのノイズに変えたときに、はじめて静けさが試される
- **学び直しにかかる時間を測る**（3章）：評価で周期を変え、新しい波が届いてから、各セルの誤差（の移動平均）が変える前の2倍以内に戻るまでの
  ステップ数。上位10%が30ステップを超えたら、2c の前に σ の窓を長くする
- ヌル対照（8章）より、「NLL と発火数」の曲線で左下にある

### 7.2 Step 2 の卒業（4本中3本以上で、次の3つをすべて満たす）

1. **驚きでの学び直し**（2c、周期を変える評価。指標は新しい波がその列に届いた時刻から測る）
   - 反応：新しい波が届いてから10ステップ以内に、波の区域の9割以上の列で発火が起きる
   - 学び直し：新しい波が届いてから300ステップ以内に、各列の NLL が変える前の水準（＋0.1 ナット以内）に戻る
   - 静けさに戻る：学び直したあと、波の区域の発火率が1%以下に戻る
   - 局所性：ノイズの区域の発火率は、周期を変えたあとも1%以下のまま（一様ノイズでは設計の保証の面が強いので、そう記録する）
2. **あきらめたセルが少ない**：波の区域で、新しい波が届いてから300ステップたっても σ が変える前の2倍より高いままのセルが **5%以下**
   （多ければ、学び直せずに慣れてしまったセルが多いということ。σ の窓を長くする）
3. **学習で見せない周期**：1 と 2 が、学習で見せない周期でも成り立つ。12 → 20（内側の見せない周期へ）と、24 → 36（外側へ）。
   落ち着いた時期の条件（7.1 の 2b）も、P=20 と P=36 で成り立つ

判定は、最後の重みか良い重みの前線（Step 1 と同じく、報告では分けて書く）。

### 7.3 DNA の価値の証明（別枠。卒業には要らない）

**学習の伝播：右の列ほど学び直しが楽になるか**
- 周期を変えたあと、各列について「新しい波が届いてから300ステップの間に、1セルあたり何回発火したか（学び直しの発火）」を数える
- 左の列は自分で学び直すしかないが、右の列は、先に学び直した左の近所の係数を DNA が知覚して借りられる（2章の「確認」の直しが前提）。
  借りられれば、**右の列ほど学び直しの発火が少なくなる**
- 指標：波の区域の右端の8列（x = 24〜31、ノイズの区域を除く行）の学び直しの発火 ÷ 左端の8列（x = 1〜8）の学び直しの発火（「左右の比」）

**2×2 の実験と、事前の予想（走らせる前に書く）**

|  | DNA あり | DNA なし（固定のデルタ則、補正なし） |
|---|---|---|
| **波の速さ 0.25列/ステップ** | **左右の比 ≤ 0.5（右の列ほど学び直しが楽）** | 左右の比 ≥ 0.8（各セルが独立に学び直す） |
| **波の速さ 1列/ステップ** | 左右の比 ≥ 0.8（光円錐の制約で、借りる意味がない） | 左右の比 ≥ 0.8 |

- **予想：4つのうち「0.25＋DNA あり」だけで、右の列ほど学び直しが楽になる**
- 読み方：
  - 予想どおりなら、伝播は「地形が許し（v < 1）、かつ DNA が借りることを学んだ」ときにだけ起きる、と言える
  - 「0.25＋DNA あり」が平らなら、地形は許しているのに DNA が借りることを学べていない
  - 「1＋DNA あり」で差が出たら、光円錐の見立てが間違っている（前線の後ろ以外の何かが効いている）
  - 「DNA なし」で差が出たら、左右の差は DNA とは関係のない別の原因（たとえば列ごとの波の条件の違い）から来ている
- あわせて、DNA ありと DNA なし（学習率の最良）を、「NLL と発火数」の曲線と、学び直しの速さで比べる（DNA が効率で何かを足しているか）

**近道の予想：「借りる」代わりに「のぞき見る」（2026-09-29、そうの指摘。走らせる前に書く）**
- DNA は近所の生の値（最近のセンサーの値を含む）を見るので、係数を借りる代わりに、**隣の値から自分の未来をのぞき見る**近道がある。
  v = 0.25 では、左隣の今の値は自分の4ステップ先の値と同じ（s(x−1, t) = s(x, t＋4)、ノイズを除く）。
  驚いた瞬間、左隣の最近の値には、新しい周期の値が4つぶん先に入っている
- **予想：のぞき見は左右の比にはほとんど効かない**。のぞけるのは隣の1列だけで、どの列でも「4ステップぶんの先取り」は同じだから
  （のぞけないのは左隣のいない x=0 だけで、比の計算には入らない）。のぞき見で速くなるのは全部の列で同じなので、比は変わらない。
  右の列ほど楽になるには、学び直した結果が発火から発火へ運ばれる（鎖になる）必要があり、値ののぞき見は鎖にならない
- **確かめ方**：伝播らしき結果（比 ≤ 0.5）が出たら、「隣の値は見せて、隣の係数は隠す」版を1本足す（8章）。
  - 比が0.8以上に戻る → 伝播は係数を借りることで起きていた
  - 比が0.5以下のまま → 伝播は係数以外の道で起きている（たとえば、発火で書き換わり近所から見える隠れの状態を、DNA が伝言に使う）。
    それも学習の伝播だが、「借りる」とは別の仕組みとして記録する

「一番良い」は、2b の落ち着いた時期の NLL と、2c の学び直しの速さで決める。両方の最良が別の値なら、両方を並べる）。
